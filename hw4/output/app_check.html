Issues found and fixed during testing

  • Chat didn't auto-expand (fixed). The first run of Check 3 failed. The overflow check ran before the reply's images (Dan reveal, thumbnails) had loaded, so the reply only overflowed after the check. ChatWidget now re-checks as those images load, for a few seconds after each new reply.
  • Count mismatch (fixed). One reply said "12 shown on the page" while 11 cards appeared, because the agent listed only 11 of its 12 results. The prompt now requires the "on the page" number to equal the cards actually returned. 3 out of 3 re-runs said 12 and showed 12.
